# A股专业分析工具

输入股票代码，从**技术面 / 基本面 / 资金面**三个维度量化打分，给出 买入/观望/回避 建议和参考买入区间。

## 功能

- **技术面（40分）**：均线趋势、MACD、RSI、KDJ、布林带、量价配合；自动计算支撑位/压力位
- **基本面（35分）**：PE(TTM)/PB 相对自身历史分位、ROE、营收与净利润增速
- **资金面（25分）**：近5日/20日主力资金净流入、最新主力动向
- **综合结论**：≥70 建议买入 / 58~69 谨慎买入 / 42~57 观望 / <42 回避，并给出参考买入区间与止损位
- **环境层（P0）**：
  - 大盘红绿灯：沪深300年线/60日线、量能、涨跌家数 → 红灯时买入信号冻结（封顶观望）、黄灯降一级
  - 行业环境：行业指数相对沪深300的20/60日相对强度 + 行业5日主力资金流排名 → 综合分 ±10 分调整
  - 财务红旗一票否决：质押比例>50%、资产负债率>85%、经营现金流/净利润<30% → 命中1条封顶观望，2条直接回避
- **板块排行榜**：选行业板块，初筛（板块内相对估值+量价）后对 Top N 做完整评分排名
- **分行业估值尺子（P1）**：科技成长用 PS/PEG/营收增速（PE失真）、金融用 PB+ROE（豁免负债率红旗）、周期用 PB分位（低PE=顶部陷阱提示）、其余用通用尺子
- **策略回测（P1）**：逐日重算历史评分（技术面+点时估值分位，无未来函数），统计高分信号日的5/20/60日前瞻胜率与超额，模拟评分策略净值 vs 买入持有（含交易成本）

数据来源：东方财富（通过 akshare），免费无需 API key。

## 运行

```bash
.venv/bin/streamlit run app.py
```

浏览器自动打开 http://localhost:8501，左侧输入6位股票代码（如 `600519`）点击「开始分析」。

## 注意

- 东方财富接口有频率限制，短时间大量查询会被临时限流（约5分钟恢复），应用内已做缓存
- 如本机开启了代理（如 Clash），程序已自动绕过代理直连国内数据源
- 本工具仅供学习研究，不构成投资建议
